# Portfolio

Single-page portfolio for Sirichai Sae-aiew (Senior Software Engineer, Full Stack). TanStack Start v1 (React 19, SSR),
Tailwind CSS v4, and `react-scroll-parallax` for scroll-linked layers.

## Setup and run

Requires Node 20+.

```bash
npm install
npm run dev        # http://localhost:3000 (Vite picks the next free port if taken)
npm run build      # client + SSR bundles into dist/
npm run start      # vite preview of the production build
npm run typecheck  # tsc --noEmit
```

No environment variables.

## Portrait

`src/components/Hero.tsx` loads `src/assets/portrait.png` or `portrait.webp` through `import.meta.glob`; with
no file the hero is type-only. The current file is a Gemini-generated 3D chibi (wai greeting) with the white
background removed. To redo the cut from a white-background JPEG:

```bash
magick in.jpg -alpha set -fuzz 10% -fill none \
  -draw "color 0,0 floodfill" -draw "color %[fx:w-1],0 floodfill" \
  -draw "color 0,%[fx:h-1] floodfill" -draw "color %[fx:w-1],%[fx:h-1] floodfill" cut.png
magick cut.png \( +clone -alpha extract -morphology Erode Disk:1.5 -blur 0x1 \) \
  -compose CopyOpacity -composite -trim +repage -resize x1600 -quality 88 src/assets/portrait.webp
```

Then update `width`/`height` on the `<Chibi>` to the new file's size.

`coffee.webp` was cut the same way from white-background JPEGs, with extra steps:

- Extra `floodfill` seeds inside enclosed gaps (between the legs, between an arm and the body), found with
  `-connected-components` on the near-white pixels that survived the first pass.
- A second pass at `-fuzz 7%` seeded inside the grey floor shadow, which is too dark for the 10% white fill.
A thin grey sliver of floor shadow remains under the feet; the `<Chibi>` contact shadow sits over it.

### Run-cycle strips

Each source is a Gemini sheet of 8 right-facing frames on white, not on a fixed grid (prompt: "run cycle
sprite sheet, 8 frames, side view, same character", one sheet per shirt). Steps per sheet:

1. Cut the whole sheet with the corner flood fill (`-fuzz 10%`). Remove enclosed gaps as pure-white regions
   (`-fuzz 2% -opaque white`) that survive `-morphology Open Disk:6`. The opening skips small highlights.
2. Find the figures with `-connected-components 8` (area threshold 20000) on the alpha. Each figure is
   masked to its own component (`connected-components:keep=<id>`, dilated 2px), since neighbours sit
   closer than a frame is wide.
3. Find each head centre: the alpha bounding box of the top 30% of the figure.
4. Crop every frame to the same box: the union of the kept figures' tops and bottoms (plus 20px), and half
   that height wide, centred on the head. Vertical offsets stay, which are the bounce. Resize to 320x640.
   Reset `-compose Over` after the mask composite, or `-extent` uses the leftover compose and blanks the frame.
5. Clear the floor shadow in the lowest 16 rows of each frame: keep only the dark-shoe span of each row
   (lightness < 100/255) plus 5px. A row with no dark pixels (the bottom of a white sole) takes the span of
   the row above.
6. `+append` the frames into the strip, `-quality 88`.

Dropped frames: The Percentage Company's frame 1, which is a front three-quarter view at a bigger scale.
In frame 6 of Lianudom and Swift Dynamics, the light fringe around the gap between the feet was cleared by
hand (lightness > 0.68, saturation < 0.2, inside a 32x40 box).

A new company needs one entry in `cycles` (its strip and frame count). Frames must be 1:2.

Contact links (`profile.links`) point to LinkedIn and GitHub. The label "Get in touch" is used for the
one call to action everywhere on the page.
